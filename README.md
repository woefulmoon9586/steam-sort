# 🎮 SteamSort - Steam 库智能分类助手

> 专为现代 Steam 客户端设计的库存游戏自动化、智能化分类工具。
> 能够一键扫描本地 Steam 库，通过游戏类型、游玩模式、特色玩法、游玩时长等多维度数据进行智能匹配，并**直接写入 Steam 官方客户端**，启动 Steam 即可看到整洁有序的分类收藏夹！

---

## ✨ 核心特性

1. **直接写入 Steam 官方客户端**
   - 深度适配现代 Steam 架构（基于 `cloud-storage-namespace-1.json` 云存储规范），支持 Steam Cloud 云同步。
   - 写入后打开 Steam 客户端即可在左侧库列表中看到生成的全新分类目录。

2. **完整支持 2024+ 新版 Steam 家庭组（Steam Families）**
   - 原生逆向解析 Valve 底层 `packageinfo.vdf` 授权包与最新版 `appinfo.vdf`（v29 字符串表二进制架构）。
   - 彻底解决传统分类工具无法扫描家庭共享游戏的痛点，100% 识别家庭库成员共享给你的所有游戏。

3. **多维度智能分类预设**
   - 🎮 **核心游戏品类**：角色扮演 (RPG)、动作冒险、射击枪战、策略战棋、模拟经营、肉鸽卡牌、解谜平台、竞速体育、恐怖生存、视觉小说与叙事、软件工具等。
   - 👥 **游玩方式与支持**：单人剧情沉浸、在线联机/合作开黑、本地同屏双人、完美支持手柄等。
   - 🌟 **热门特色题材**：开放世界、类魂高难受死、像素复古、休闲治愈、赛博朋克等。
   - ⏳ **库存消化与状态**：深度沉迷 (50h+)、正在游玩 (10-50h)、浅尝辄止 (1-10h)、待开坑库存 (0h)。
   - 🔥 **玩家好评口碑**：好评如潮 (95%+)、特别好评 (80-94%)。

3. **可视化交互与自由微调**
   - 优雅的 Steam 风格暗色界面，支持分类前实时预览每一款游戏的封面、时长与标签。
   - 自由重命名分类、添加自定义 Emoji、增删游戏、创建属于自己的自定义分类。
   - 支持“跨分类归类”（如既是 RPG 又是联机游戏）或“排他单一分类”。

4. **安全写入与一键还原**
   - **进程安全检测**：写入前自动检测 Steam 运行状态，防止客户端热覆盖。
   - **自动时间戳备份**：每次写入前自动生成完整快照。
   - **一键还原中心**：如果不满意，可随时在网页中一键回退到任何历史状态。
   - **合并模式选择**：支持追加合并（保留原分类）、重生成分类或全新整理。

## 🚀 快速启动

### 方式一：双击启动（Windows 推荐）

直接双击运行项目根目录下的 **`start.bat`** 脚本即可：
- 脚本会自动检查环境、安装依赖、构建前端并自动在默认浏览器中打开 `http://localhost:3001`。

### 方式二：命令行启动 Web 界面

```bash
# 1. 安装依赖
pnpm install  # 或 npm install

# 2. 启动服务（自动构建并启动本地 Web 界面）
pnpm start
```
启动后在浏览器访问：**`http://localhost:3001`**

### 方式三：极客 CLI 快速命令行模式

如果你不需要网页界面，只想一键分类：

```bash
# 查看分类预览与匹配结果（不修改 Steam 文件）
node cli.js

# 直接应用并写入 Steam 客户端（请确保先退出 Steam）
node cli.js --apply
```

## 📖 使用向导

1. **第 1 步：环境与库存识别**
   - 系统会自动检测您的 Steam 安装路径（如 `E:\Steam`）与登录过的账号。
   - 自动扫描本地安装的游戏与历史库缓存（包括时长与游玩记录）。
   - *(可选)* 支持输入 Steam Web API Key 拉取全部从未安装过的游戏。
2. **第 2 步：选择分类方案**
   - 勾选您心仪的分类方案（支持多选）。
   - 选择是否允许游戏跨分类（推荐开启，体验与官方收藏夹一致）。
   - 点击“开始智能分类”，系统将自动匹配游戏元数据与标签。
3. **第 3 步：预览与微调**
   - 查看生成的分类列表与所属游戏海报。
   - 可以在线重命名分类、删除不喜欢的分类、拖拽或调整游戏。
4. **第 4 步：安全写入 Steam**
   - 确认退出 Steam 客户端（界面提供一键退出按钮）。
   - 选择合并模式（推荐“追加合并”）。
   - 点击“立即写入并分类 Steam 库”。
   - 打开 Steam 客户端，享受焕然一新的游戏库！

## 🛠️ 技术架构

- **后端**：Node.js + Express 5
- **前端**：React 19 + Tailwind CSS 4 + Vite + Lucide Icons
- **Steam 协议支持**：
  - Valve KeyValues (VDF) 自研高效解析与序列化引擎
  - Valve CloudStorage Namespace 1 JSON 现代云存储同步规范
  - Steam Store API + SteamSpy API 多级本地持久化缓存引擎
- **本地安全性**：100% 本地运算，不搜集任何玩家隐私信息。
